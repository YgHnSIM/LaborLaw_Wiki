# 번들 글꼴 보존 지침

## 범위

이 디렉터리는 사이트가 로컬에서 제공하는 MaruBuri·RIDI Batang·D2Coding 글꼴과 라이선스·출처 메타데이터를 보관한다. 일반 JavaScript·CSS 규칙은 상위 `site/AGENTS.md`를 따른다.

## 바이너리 계약

- 글꼴 바이너리를 재압축·변환·재인코딩·덮어쓰기하지 않는다.
- 기존 파일명과 경로를 바꾸지 않는다. 교체가 필요하면 원본·라이선스·출처·해시와 변경 사유를 함께 검토한다.
- `OFL.txt`, `SOURCE.md` 등 라이선스·출처 파일을 글꼴 바이너리와 함께 보존한다.
- 로컬 글꼴을 외부 CDN으로 바꾸거나 Pages 산출물 밖의 임의 자산을 참조하지 않는다.

## 검사

글꼴·출처·CSS를 변경하면 `npm test`의 헤더·라이선스·SHA-256·크기 예산 검사를 통과시키고 `npm run build`로 실제 자산 복사를 확인한다. `_site/assets/fonts/`는 산출물이므로 직접 수정하지 않는다.

## 범위 밖

글꼴 파일을 교체하는 작업은 사이트 전체의 폰트 스택·줄바꿈·모바일 가독성에 영향을 줄 수 있으므로 상위 사이트의 수동 확인 경계도 따른다. 글꼴과 무관한 화면·검색·템플릿 변경은 이 문서에 규칙을 복제하지 말고 `site/AGENTS.md`에서 관리한다.
